# Live Flood-Aware Map

A real-time map web app that helps you travel safely when it rains.

## Features
- Routes for car, bike and walk, with several vehicle types
- Live rain data along your route with flood and waterlogging warnings
- Safer alternative route suggestions and delay estimates
- Crowd-sourced flood reports that everyone sees on the map
- Real GPS tracking: the icon moves only when you move
- Search for places, metro stations, bus stops and shops, or pin a spot on the map
- Dark and light mode, plus street and satellite map views

## Tech
Python (Flask), HTML, CSS, JavaScript, Leaflet, OpenStreetMap, Open-Meteo
